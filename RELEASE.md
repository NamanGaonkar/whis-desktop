# Whis Desktop v1.0.0 Release Notes

Welcome to the initial release of **Whis Desktop**!

### What's New
- **Dedicated Whis Terminal**: Streamline your workflow with real-time interactive terminal emulation powered by `@xterm/xterm` and `node-pty`.
- **Dynamic Dual Theme**:
  - Warm Golden Studio theme for bright environments.
  - Deep Obsidian theme with warm amber highlights for nighttime focus.
- **Provider & Model Switching**: Add, edit, test, and switch between Anthropic Claude, OpenAI, Google Gemini, DeepSeek, Groq, Ollama, and custom endpoints.
- **Encrypted Secrets**: Seamless API key encryption backed by operating system DPAPI / Keychain.
- **Multi-platform Distribution**: Windows setup installer, portable executable, macOS DMG, and Linux AppImage.
